# Log de trabalho simultâneo (múltiplas IAs)

Mais de uma IA pode estar trabalhando neste projeto ao mesmo tempo. Este arquivo existe pra
evitar que duas IAs mexam na mesma área do código ao mesmo tempo e criem conflito.

**Regra**: antes de começar qualquer tarefa, releia este arquivo inteiro. Se a área que você vai
mexer (arquivos, pasta, sistema) estiver listada como `EM ANDAMENTO` por outra IA, não comece —
avise o usuário e espere. Se estiver livre, adicione uma entrada no topo da lista abaixo com
status `EM ANDAMENTO` antes de tocar em qualquer arquivo. Quando terminar (ou parar) a tarefa,
volte aqui e mude o status pra `CONCLUÍDO` (ou `INTERROMPIDO`, se não terminou).
